--------------------------------------------------------------------------------
1. PROJECT ARCHITECTURE & CORE STACK
--------------------------------------------------------------------------------
Backend:
- FastAPI (Python 3.11+) asynchronous REST API
- SQLAlchemy ORM with SQLite (Development) / PostgreSQL (Production)
- Pydantic v2 schemas for request validation & serialization
- JWT authentication with role-based access control (Student & Vendor)
- Twilio SMS / OTP service with development console bypass
- Uvicorn ASGI server running on port 8080 (0.0.0.0 for LAN access)

Frontend:
- React 18 with Vite SPA architecture
- TanStack React Query for caching, optimistic updates, and background refetching
- Framer Motion for spring physics, sheet modals, and page transitions
- Canvas-Confetti & Web Audio API for feedback
- Pure vanilla CSS custom properties design system (Single-file index.css)
- Vite proxy mapping /api and /uploads to http://127.0.0.1:8080
